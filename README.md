# AI-администратор бизнеса

Универсальное Next.js приложение для онлайн-консультаций и записи клиентов офлайн-бизнеса. Код не зависит от ниши: факты находятся в `data/business.json`, роль и правила — в `data/system-prompt.txt`. Поле `niche` служит только меткой.

## Запуск локально

Нужны Node.js 20+ и npm. Создайте `.env` из `.env.example`, задайте `SESSION_SECRET`, `ADMIN_PASSWORD` или `ADMIN_PASSWORD_HASH`, затем выполните:

```sh
npm ci
npm run db:deploy
npm run db:seed
npm run dev
```

Откройте `http://localhost:3000`; панель администратора — `/admin/login`. Демо-логин и пароль берутся из env (`admin` и `change-this-password` по умолчанию). Перед публикацией задайте собственный пароль и секрет сессии. Для `ADMIN_PASSWORD_HASH` используйте bcrypt-хеш; он имеет приоритет над `ADMIN_PASSWORD`.

В разделе «Настройки» администратор может сменить пароль, указав текущий и новый. Локально bcrypt-хеш сохраняется в файл данных; в Layero — в подключённую PostgreSQL, чтобы он переживал перезапуски. После смены прежние сессии перестают действовать.

Раздел «Данные бизнеса» содержит отдельные поля для контактов, дней и часов работы, услуг и цен, заблокированного времени, виджета и уведомлений. Услуги можно добавлять и удалять. Локально изменения записываются в `data/business.json`; в Layero — в PostgreSQL. В обоих случаях конфигурация перечитывается без перезапуска.

По умолчанию `LLM_PROVIDER=mock`, поэтому проект работает без ключа провайдера. Для OpenAI-совместимого Chat Completions API задайте `LLM_PROVIDER=openai`, `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Администратор может изменить модель, температуру и лимит токенов в панели. Ключ остаётся на сервере.

## Layero

Для Layero приложение использует предоставляемую платформой переменную `LAYERO_DATABASE_URL`. Подключите PostgreSQL к проекту в панели Layero: при запуске применятся отдельные PostgreSQL-миграции. Без подключения сайт можно открыть, но записи, вход в админку и сохранение настроек требуют доступной базы. Не задавайте `output: standalone`: Layero запускает Next.js как серверное приложение.

Сборка генерирует Prisma-клиенты для SQLite и PostgreSQL; выбор делается по `LAYERO_DATABASE_URL` или типу `DATABASE_URL`. Для Neon CLI `DATABASE_URL` — пулер для запросов приложения, а `DATABASE_URL_UNPOOLED` — прямое подключение для миграций. Внешние секреты остаются только в env и не попадают в Git.

## Встраивание виджета

Вариант с iframe:

```html
<iframe src="https://ваш-домен/widget" title="Чат с администратором" style="width:100%;height:650px;border:0"></iframe>
```

Плавающая кнопка и изолированные стили через web component:

```html
<script src="https://ваш-домен/ai-business-widget.js" defer></script>
```

Для внешнего сайта добавьте его origin в `ALLOWED_ORIGINS`. Настройки кнопки, позиции, цвета, аватара, приветствия и быстрых ответов загружаются из бизнес-конфига.

## Другая ниша

Замените `data/business.json` и `data/system-prompt.txt` либо отредактируйте их в панели. Валидатор проверяет данные до сохранения; активные изменения подхватываются без перезапуска. Демо-цены автосервиса — пример структуры, замените их перед запуском.

## Записи и уведомления

Посетитель выбирает активное предложение и свободное время в форме виджета. Конфликтующие и заблокированные слоты отклоняются сервером, новая запись получает статус `pending`. Администратор подтверждает или отменяет её. Клиент может указать email для подтверждения и получения ссылки отмены.

Для SMTP задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`; для уведомлений администратора через Telegram — `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID`, а также включите канал в `business.json`. Без настроенного транспорта уведомитель работает в no-op режиме. `APP_BASE_URL` используется в ссылке отмены. Напоминания проверяются каждые 15 минут; задайте `CRON_SECRET` и `INTERNAL_BASE_URL`.

## Проверки

Перед тестами примените миграции. Затем выполните:

```sh
npm test
npm run lint
npm run build
```

Тесты проверяют валидацию и смену конфигурации без перезапуска, часовой пояс и заблокированные интервалы, безопасный markdown, лимиты запросов, поведение mock-ассистента, отказ при недоступном провайдере, идемпотентность и конкурентное создание записей.

## Docker

Создайте `.env` с секретами и запустите:

```sh
docker compose up --build
```

Контейнер применяет Prisma-миграции при запуске. Конфиг и SQLite хранятся в томе `business-data`; контейнер работает от непривилегированного пользователя.
